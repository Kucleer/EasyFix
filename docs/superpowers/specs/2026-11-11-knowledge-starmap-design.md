# 项目 2：考点掌握度与知识星空 设计

日期：2026-11-11
状态：草稿，待用户确认
范围：路线图里的"项目 2：教材章节与掌握度"，经讨论后改为本文的样子。
相关文件：`docs/superpowers/specs/2026-11-10-optimization-roadmap.md`；demo `docs/superpowers/specs/2026-11-11-knowledge-starmap-demo.html`（数据是示意的，直接用浏览器打开）。

标记说明：**【用户定】** 是用户在讨论中明确说的；**【Claude 定】** 是 Claude 的判断，用户可以推翻；没有标记的是两者共同推出、或对现有系统的描述。

## 1. 为什么做

家长需要随时知道孩子哪些考点没掌握，好去补强。**【用户定】**
更深一层，要把掌握情况画成一张好看、会动的"知识星空"，用颜色和高亮直观展示掌握程度，激发孩子的学习兴趣。**【用户定】**

现在系统里没有"考点掌握度"这个值。考点表只有名称、年级、学期、上下级。和掌握有关的只有每道错题的复习次数，以及单词本的正确率。这一期要做的就是把这个值建起来，星空是它的展示方式。**【用户定】**

## 2. 目标、不做的事、要避免的结果

### 目标

1. 每个考点有一个掌握度，按"最近的做题结果"变化，可以手动调。
2. 用沪教版教材初始化星空：有哪些星、怎么分组、哪些已经学过。
3. 一张红黄绿配色、像 Obsidian 关系图那样的知识星空，有动画，首页有缩略图，有独立页面。
4. 每次有考点达到"掌握"，有一个"点亮时刻"的动画。
5. 英语按课程标准的语法体系重建考点，并加一个词汇星团。

### 不做

- 不录入作业里做对的题。**【用户定】** 掌握度只靠错题、练习卷结果和手动调整。
- 不按时间推移自动变亮或变暗。**【用户定】**
- 平板和手机的适配这一期不做，先做电脑，布局留余地。**【用户定】**
- 不改现有两级考点树的结构和已有错题的数学考点标签。
- 不做"按掌握度自动出题"——那是项目 3。
- 不做按教材章节的"学习进度自动推断"（路线图原计划）。改为见 5.4 的做法。**【Claude 定】**

### 要避免的结果

- 页面做出来"能用但不好看"。好看是这一期的硬要求。**【用户定】**
- 星空上字太多、没有动画。**【用户定】**
- 没学过的考点被当成薄弱，或者显示成"半掌握"。
- 孩子能自己把星星调成掌握。手动调整只放在管理设置里，孩子不知道管理密码。**【用户定】**
  现状说明：管理设置的密码就是网站的访问密码（`ACCESS_PASSWORD`），没有单独的管理密码。孩子不知道这个密码、由家长登录，所以目前够用，这一期不加单独的管理密码。以后孩子自己登录时要重新考虑。
- 统计口径不一致：待核对的题（项目 1 的 `review_status='pending'`）不参与掌握度计算。

## 4. 掌握度怎么算

掌握度是 0 到 1 之间的一个数，**每次读取时现算**，不存结果（路线图约定"读取时计算"）。数据量很小：约 600 道错题、约 700 条练习结果。

### 4.1 用到的事件

按时间先后排成一条记录，每条记录属于一个或多个最底层考点：

| 事件 | 来源 | 时间 | 效果 |
|------|------|------|------|
| 出现一道错题 | `question`（未删除、`review_status` 为 `approved`）及其 `question_knowledge_point` | 卷子的 `paper_date`；属于"历史作业"卷子（`paper.source='history'`）时用错题的 `created_at` | 一次"错" |
| 练习卷里这道题做对 | `practice_set_question.is_correct=1`，练习卷未删除 | 练习卷的 `last_reviewed_at` | 一次"对" |
| 练习卷里这道题做错 | `practice_set_question.is_correct=0` | 同上 | 一次"错" |
| 手动调整 | 新表，见 6.2 | 调整时间 | 加或减一个幅度，见 4.4 |

- 一道题关联多个考点时，每个关联的考点都记一次。主考点和关联考点同样对待。**【Claude 定】**
- 错题的时间优先用卷子日期，因为录入日期可能比做题晚几天；历史作业卷子的日期是回填出来的，不可靠，所以这类题用录入时间。同一时刻的事件，错题排在练习结果前面。**【Claude 定】**
- 练习卷重新批改会覆盖原来的对错，并更新 `last_reviewed_at`；计算时只认最新一次批改的结果和时间。这是现有数据的样子，这一期不改。**【Claude 定】**
- 错题复习页面的对错、作业本上的订正都不算。**【用户定】**

### 4.2 最底层考点

1. 起点：学过的考点从 **0.5** 开始；没学的考点不计算，显示为"没学"（见 5.4）。
2. 按时间顺序处理事件：
   - 一次"错"：减 **0.15**。
   - 一次"对"：加 **0.15**。
   - 结果限制在 **0.15** 到 **0.99** 之间：靠加减到不了 1，只有下一条"最近 3 次全对"或手动"直接设为掌握"才是掌握。**【Claude 定，整体审阅后补充】**
3. 如果这个考点**最近 3 次**"对/错"事件全部是"对"，掌握度直接为 **1**（掌握）。手动调整不算在这 3 次里。
4. 已经掌握后又出现"错"，这次错进入"最近 3 次"，掌握度从 1 开始扣。**【Claude 定，按"只看近期结果"推出】**

每次加减 0.15、底层 N = 3 是 Claude 定的初始值，做成配置项，以后可以改。**【Claude 定】**

例：起点 0.5 → 错 0.35 → 错 0.2 → 对 0.35 → 对 0.5 → 对：最近 3 次全对，变成 1。

### 4.3 上层星（一级模块，以及以后可能出现的更多层）

- 上层星的事件 = 它下面所有底层考点的事件合在一起。
- **N = 3 × 它覆盖的底层考点数，最多 30**。例："整除与因倍数"有 3 个考点，N=9；"有理数"有 11 个，N=30。**【用户同意方向，上限 30 是 Claude 定】**
- 上层星的掌握度 = 下面已学考点掌握度的平均值。
- 上层星算"掌握"需要同时满足：**至少有 N 次**对/错事件，最近 N 次里"对"的比例至少九成，下面没有"没学"的考点，并且已学的子考点都至少"较好"（0.7）。满足时掌握度为 1。**【Claude 定；最后一条是整体审阅后补充，避免练习集中在少数考点时整个模块变绿】**
- 不满足时，上层星的掌握度最高显示 0.99（较好，黄绿色），即使下面所有考点都已掌握。**【Claude 定】**
- 顶部的"已掌握 X 颗"和点亮时刻只数**最底层考点**，不数模块和词汇星团。**【Claude 定】**
- 规则不依赖具体层数：每颗星都按它覆盖的底层考点来算。

### 4.4 手动调整

管理设置里，家长可以对任何一颗星做调整：

| 选项 | 效果 |
|------|------|
| 提高一点 | +0.15 |
| 提高很多 | +0.35 |
| 直接设为掌握 | 设为 1 |
| 降低一点 | −0.15 |

- 调整作为一条事件，按时间插进序列。之后的错题和练习结果在调整后的值上继续加减。**【Claude 定】**
- 对上层星的调整，作用到它下面每个已学考点。**【Claude 定】**
- 手动调整不计入"最近 N 次"。
- 每条调整都保留记录，可以撤销（软删除）。

### 4.5 状态和颜色

| 掌握度 | 状态 | 颜色 |
|--------|------|------|
| 没学 | 没学 | 灰色，几乎看不见 |
| 0.15 – 0.4 | 薄弱 | 红到橙 |
| 0.4 – 0.7 | 一般 | 橙到黄 |
| 0.7 – 0.99 | 较好 | 黄到黄绿 |
| 1 | 掌握 | 绿色 |

颜色按掌握度连续渐变，表里的分档只用于文字说明。**【Claude 定】**

## 5. 星空里有哪些星

### 5.1 数学

- 星：现有的六年级数学两级考点（9 个一级模块，42 个二级考点）。
- 教材：沪教版（五四制，2024）六年级上册，目录来自公开资料（教习网），与用户截图一致：
  - 第 1 章 有理数（1.1–1.5）
  - 第 2 章 简单的代数式（2.1–2.3）
  - 第 3 章 一元一次方程（3.1–3.3）
  - 第 4 章 线段与角（4.1 线段、4.2 角）
- 章节对应到**二级考点**，按"节"对应（例：4.1 线段 → 线段和差与中点；4.2 角 → 角的度量与和差、角平分线）。具体对应表由 Claude 起草，和先学后学连线一起给用户确认。一个考点没有对应到任何一节时，按它所属模块对应的章来算。**【Claude 定】**
- 章和模块的大致对应：第 1 章 → 有理数，第 2 章 → 简单的代数式，第 3 章 → 一元一次方程，第 4 章 → 线段与角。
- 整除与因倍数、分数基础与应用、图形与几何、数量关系与应用、规律探索与综合应用：课本里没有对应章节（五年级或拓展内容），视为已学（路线图约定）。

### 5.2 英语语法

- 不按教材，按《义务教育英语课程标准（2022 年版）》附录的语法项目整理成两级考点（一级如"动词时态""句型"，二级如"一般过去时""特殊疑问句"）。**【用户定】**
- 每条二级考点标上大致在几年级学。**【用户定，Claude 提议】**
- 整理结果先给用户看一次，确认后入库。
- 现有英语错题按新体系重新打标签：Claude 先逐题归类，拿不准的列给用户看。**【用户定】**
- 重新打标是**替换**：每道英语错题的旧考点关联软删除，换成新的语法考点关联；旧的英语考点也软删除，避免统计里两套体系重复计数、避免新旧一级考点重名。软删除的数据保留在库里，需要时可以恢复。**【Claude 定】**
- 之后录入（项目 1 的录入接口）、手工录题和编辑错题时，英语只提供新的语法考点。**【Claude 定】**
- 单词拼写、词汇类的错题不进语法星空，由词汇星团体现。

### 5.3 英语词汇星团

- 英语下面最大的一级星团。**【用户定】**
- 掌握度 = 已掌握的单词和词组数 ÷ 单词本里的单词和词组总数（未删除）。"已掌握"沿用单词本列表里"掌握"筛选的标准：复习过、正确率超过 80%。单词本顶部统计里另有一个更严的"掌握"数（复习至少 5 次且正确率至少 90%），两者不同，星空用前者，和单词本列表的筛选结果一致。**【Claude 定，沿用现有】**
  - 现在的数字：单词 748 条，掌握 297 条；词组 222 条，掌握 37 条；合计 334 / 970，约 34%。
- 词汇星团只是一颗星，这一期不细分。
- 掌握比例达到 25%、50%、75%、100% 时，星体各长大一级。**【用户定方向，阈值是 Claude 定】**
- 它不参与 4.2–4.4 的规则，也不能手动调整。**【Claude 定】**

### 5.4 哪些算"学过"

- **数学**：管理设置里有一项"现在学到哪一节"，初始为 4.2。这一节及之前各节对应的考点算学过，之后的算没学。课本外的模块全部算学过。**【Claude 定】**
- **英语语法**：标注年级不高于孩子当前年级的考点算学过。当前年级取应用默认年级。
- **兜底**：一个考点只要出现过错题或练习结果，就算学过，不管进度设置。**【Claude 定】**
- 以后换学期、换课本，需要另外初始化新教材的章节对应。这一期只做六年级上册。

### 5.5 星和星之间的连线

- **属于关系**：考点连到它的一级模块。
- **先学后学关系**：比如"有理数加减 → 有理数乘除 → 乘方 → 混合运算"。由 Claude 按课本顺序和知识依赖起草，用户确认一次后入库。这一期不做编辑界面。**【Claude 定】**
- demo 里的连线是草稿，不是最终版。

## 6. 数据

结构变更只追加 `cloudflare/migrations/` 迁移，所有新表都有 `deleted` 字段和 `student_id`（沿用项目 1 的约定，默认 1）。

### 6.1 新增的考点数据

- 英语新语法体系：写进现有 `knowledge_point` 表（`subject_id` 为英语，`level` 1 和 2），用新的 `code` 前缀区分。
- 英语语法考点"大约几年级学"：**新加一列**存放，不能用 `knowledge_point.grade`——录入接口按 `grade` 过滤考点目录，用它会让六年级录入时看不到三到五年级学过的语法。英语语法考点的 `grade` 留空，表示各年级通用。**【Claude 定】**
- 章节对应：新表，记录"教材、节号（如 4.2）、节名、所属章、对应的二级考点"。
- 先学后学连线：新表，记录"先学的考点、后学的考点"。

### 6.2 手动调整记录

新表：考点、调整类型（4.4 的四种）、时间、是否已撤销。

### 6.3 学习进度

"数学现在学到哪一节"存在现有的应用配置里（`runtime_config`，与默认年级学期同处）。

### 6.4 点亮时刻需要的记录

"孩子上次看到时已经掌握的考点"存在服务器上（应用配置或单独一行），不放浏览器本地，换电脑也不会重复播放。**【Claude 定】**

- 第一次上线时，这个集合初始化为当时已经掌握的考点，不会一打开就把所有已掌握的星一起播放。
- 一个考点掉出掌握（又出现错题）时，从集合里去掉；以后再次掌握，会再播放一次点亮时刻。
- 也就是说，存的是一个集合，和当前的掌握情况比较；不需要单独的掌握事件日志。

## 7. 接口

- `GET /api/starmap?subject=数学`：返回这一科的全部星（编号、名称、层级、所属模块、状态、掌握度、最近几次对错、相关错题数）、连线，以及"自上次查看以来新掌握的考点"。英语额外返回词汇星团的数字。一次请求，服务端用 SQL 聚合完成，不逐个考点查询。
- `POST /api/starmap/seen`：记下孩子已经看过的掌握考点（点亮时刻播放完后调用）。
- 管理设置用：
  - 列出和新增手动调整、撤销调整。
  - 读取和修改数学学习进度。
- 待核对的题不参与计算，沿用项目 1 的 `question_scope.COUNTED`。

## 8. 页面

以 demo 为准：`docs/superpowers/specs/2026-11-11-knowledge-starmap-demo.html`。在页面上切到"红黄绿"就是确定的方案。金色方案不做。

### 8.1 知识星空页（新菜单项"知识星空"，全屏深色）

- 关系图：力导向布局，可以拖动、缩放，整张图缓慢漂移。
- 星：圆点加光晕，颜色按 4.5 表；掌握度越高，光晕越大越亮。**没有星芒。**
- 连线：颜色取两端星的中间色；点亮的连线上有光点流动。
- 背景：细密的微尘、很淡的装饰网络、若隐若现的公式（英语页是语法句式）。
- 字：平时不显示考点名称。鼠标移上去浮出名字；点一下，右下角出现小卡片（名字、掌握度条、状态一句话）。
- 悬停：**不压暗其他星**；被悬停的星有扩散的光环，相连的线变亮变粗、流动加快，相连的星稍亮。
- 顶部：数学 / 英语切换、"已掌握 X 颗"。左下角一行小图例。
- 进入页面时如果有新掌握的考点，自动播放点亮时刻。

### 8.2 点亮时刻

- 新掌握的考点依次变成绿色，迸发一团粒子并扩散光环，屏幕中间浮现"点亮了 N 颗星"。
- 播放完调用 7 的 `seen` 接口。

### 8.3 首页缩略图

- 首页一张卡片，显示同样会动的星空缩略图和"X 颗星已掌握"，点击进入星空页。放在首页的哪个位置，实施时按首页布局决定。**【留给实施者】**

### 8.4 管理设置

- 新的一栏"知识星空"：
  - 数学现在学到哪一节。

### 8.5 技术
