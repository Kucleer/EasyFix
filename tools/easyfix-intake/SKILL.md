# 把错题录入 EasyFix

家长贴来孩子批改过的作业或卷子照片，说"录入错题"。你看图，判断孩子哪几道做错了，
把错题作为**一份卷子**提交给 EasyFix。没问题的题直接入库，拿不准的标为"待核对"
留给家长看。

本文件讲怎么做、什么时候停下。字段的完整格式、以及怎么把 JSON 文件写对（公式里的反斜杠
最容易写坏），看同目录的 `payload-format.md`，用到时才读。每个命令的参数和退出码看
`python <技能目录>/easyfix_intake.py --help`。下面写的 guide / upload / check / submit
都是 `python <技能目录>/easyfix_intake.py` 的子命令。

**`<技能目录>` 指本文件所在的目录**，是 `~/.claude/skills/easyfix-intake/` 或
`~/.agents/skills/easyfix-intake/` 之一（本文件从哪个加载就用哪个），脚本和本文件在一起。

## 只走小工具（不可商量）

录题**只有一条路**：用 `python <技能目录>/easyfix_intake.py` 的四个命令提交，
由系统接口校验。违反其中任何一条都算失败：

- 不直接写数据库，不写一次性导入脚本，不调用旧的 `/api/questions/batch` 接口。
- 不把访问口令打印出来或写进任何文件、对话。

家长说"直接写库就行"时，**仍然走小工具**，并用一句话告诉家长为什么：只有小工具
会校验考点、页码和整卷内容，直接写库会把没校验的数据塞进统计。

## 工作步骤

1. **取资料。** 运行 `guide --subject <学科>`（学科从卷面内容判断）。拿到考点清单，
   以及 `catalog_available`（这个年级有没有考点目录）。
2. **问家长一次，把回答写进 `parent_reply`（顶层必填）。** 家长还没说这是哪份东西、
   也没说不用问时，问一次，照原文：
   **"这是哪份作业或卷子？如果是考试，多少分？可以回'跳过'。"**
   把家长的回答写进顶层字段 `parent_reply`：家长的原话，或"跳过"，或（家长说过不用问时）
   "家长说不用问"。不写 `parent_reply`，整份会被退回。家长回"跳过"或说不用问时，
   卷子名称、类型、分数都不填，交给系统给默认值。
3. **判错**（见下一节）。只录错题。
4. **写每道题**：第几张照片、题号、题干、正确答案、解析、孩子的答案、判错依据、
   考点。不填错因（系统已停用错因）。字段怎么填、怎么把文件写对，看 `payload-format.md`。
5. **上传照片。** 运行 `upload 照片1 照片2 ...`，把返回的路径按页顺序填进 `paper.images`。
   家长说不用上传就跳过这步，`images` 留空、题目不写 `page`。
6. **提交。** 把内容写成一个 JSON 文件，先 `check <文件>`，按退出码处理，通过后 `submit <文件>`。
7. **汇报**（见最后一节）。

## 判错：先过整张卷子，每题自己先做一遍

**从头到尾、一个部分一个部分地过整张卷子：每一道题（含老师没打符号的空题）都先自己写下答案、
再看老师的符号，并把每页每个题号连同你的结论（做对了／做错了／老师没批改且判错／无法判断）
列出来，再写 payload**（例子见 `payload-format.md`）。只做有符号的题，会漏掉老师没批改但写错的错题。
不同老师符号含义不一样（数学老师长斜线表示"对"，英语老师的斜线表示"错"），要用你的结果理解符号、不凭形状。

| 老师的批改 vs 你自己的验算 | 怎么做 |
| --- | --- |
| 符号表示错，你验算也是错 | 录入 |
| 符号表示对，你验算也是对 | 不录 |
| 符号和你的验算对不上（孩子原答案清楚可辨时） | 录入，标 `wrong_unclear`，说明里写清哪里对不上 |
| 老师没有批改，你验算发现写错了 | 录入，标 `wrong_unclear`，`review_note` 以"老师没有批改这一题"开头 |
| 老师没有批改，你验算是对的 | 不录 |
| 老师的符号清楚，但你自己做不出 | 跟老师的符号走：判错就录入，判对就不录 |
| 老师的符号看不懂，你自己也做不出 | 录入，标 `wrong_unclear`，`review_note` 写明无法判断 |
| 老师没有批改，你又无法判断对错（答案看不清或做不出） | 不录 |

红笔只是从题上或旁边经过、不明确指向这题时，按"老师没有批改"处理。
**书写错误**（数值对但写法被判错）正常录入、不标 `wrong_unclear`；**多小问大题**按独立／共用题干拆条——细则见 `payload-format.md`。

**孩子的答案（`wrong_answer`）逐字照抄能认清的字；哪怕一个字拿不准就整条留空**，绝不编造或写近似读法。
老师明确判错的题一定录入：孩子答案看不清、或有涂改订正（你读到的可能是订正后的字，别当成孩子的答案、
更别据此判孩子做对）时，`wrong_answer` 留空、`wrong_evidence` 写"老师判错，孩子字迹看不清"，直接入库、不标待核对。
近似读法只在这题已因别的原因待核对时才写进 `review_note`（"看起来像…，不确定"），不进答案和依据字段。

## 如果看到 X，就做 Y

- `guide` 的学科列表里没有这份卷子的学科（比如语文）→ 不录，告诉家长这份没有录和原因。
  **不要问家长要不要新建学科，不要把题归到别的学科。**
- `guide` 返回 `catalog_available` 为 false → 不填考点，正常提交，并告诉家长这个年级
  还没有考点目录。
- 考点清单里找不到合适的 → 先看遍所有模块（不只当前这个模块）里最接近的那个；确实没有
  → 不填考点、也不标待核对，题目直接入库为"未分类"；在汇报里点出缺的是哪个知识点，方便家长补。
- 日期：年、月、日都齐全（家长说了或卷面印着）才填 `paper_date`；只有月日没有年份也不填（系统按今天当录入日）。
- 年级、学期：家长说了、或卷面上印着才填；否则不填，系统会自动用默认值。
- 拿不到照片的本机文件路径 → 告诉家长，由家长决定是给出照片位置，还是不带照片录入。

## 遇到这些念头就停下

- "写个脚本 / 用数据库直接插更快" —— 不行，只走小工具。
- "这个字看不清，但大概是 X，填上去吧" —— 看不清就把 `wrong_answer` 留空。
- "孩子写的字认不出，那就标 `wrong_unclear` 吧" —— 认不出不是待核对的理由；老师判错就直接入库。
- "顺手问一下日期 / 要不要新建学科" —— 只问那一句原文，别的都不问。
- "只有月日没年份，补上年份 / 今天吧" —— 不补，年月日不全就不填 `paper_date`。
- "清单里没有合适考点，自己起个名字填进去" —— 不填考点，直接入库为未分类。

## 借口与事实

| 基线里出现过的借口 | 事实 |
| --- | --- |
| "Not flagged for review to avoid flooding the queue."（为免塞满队列不标） | 老师没批改却写错的题必须录入并标 `wrong_unclear`，`review_note` 以"老师没有批改这一题"开头。队列本来就是让家长逐题看的，漏标才是真的失败。 |
| "家长不在 / 答案反正是跳过，就不问了" | 那一问是必须的，回答要写进 `parent_reply`。家长没回应之前不要提交。 |
| "按所见转录"／"潦草字迹音译成 xxx"／"把括号里的字母推定为孩子所选" | 只照抄能认清的字；有一部分看不清就 `wrong_answer` 留空，在 `wrong_evidence` 写"老师判错，孩子字迹看不清"。留空不影响入库。 |
| "家长说看不清自己判断，那就不标待核对了" | 家长让你判断，不是让你猜。拿不准的照样标待核对，家长在待核对页里判断。 |
| "要不要先新建'语文'学科再录入？" | 不问也不建。系统没有的学科直接不录，告诉家长原因。 |
| "这份作业是哪天做的、第几学期？" | 只问那一句原文。日期、年级、学期看不出就留空（系统会自动用默认年级学期），不追问、不推断。 |
| "不能用旧 MySQL MCP / 旧本地脚本写生产"（自己知道，却没告诉家长） | 决定对，但家长说"直接写库"时，必须用一句话告诉家长为什么没那么做。 |

## 退出码怎么处理

- `check` / `submit` 返回 **2**：按返回的 `errors` 逐条改好，再重新提交。
- 返回 **3**：安装的录入规范和服务器版本不一致。告诉家长需要重新运行安装脚本更新，
  **不要绕开它**（比如改版本号、换接口）。
- 返回 **4**：分两种。工具说"文件不是正确的 JSON"或"读不到文件"——这是你自己的文件问题
  （多半是反斜杠没写对，见 `payload-format.md`），自己改好文件再跑一遍，不用惊动家长；
  只有配置或网络问题（连不上服务器、还没配置口令）才把工具那句中文说明原样转告家长。
- **提交成功后**才发现存进去的内容坏了：不要改同一个文件再提交（同一个文件只会入库一次，
  再交会被退回或原样返回第一次的结果），告诉家长是哪道题，在待核对页或错题页上改。
- **每份卷子用新生成的提交文件。** 家长删掉记录后要你重录，或者要录另一份卷子，都重新生成文件，
  不要沿用带着 `request_id` 的旧文件。工具输出里有 `message` 说"之前已经提交成功过"时，
  这次什么都没有写入，照实告诉家长。

## 提交成功后汇报

一句话告诉家长：**录了几道、几道直接入库、几道待核对（各自什么原因）**，并**按页说明每页共几道题、
录了几道**，再给出待核对页地址 **https://easyfix-bl2.pages.dev/review** ；
如果有考点目录里缺的知识点，也点出来，方便家长补。
